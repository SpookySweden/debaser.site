PROFILE PICTURES
================

Drawings in here are the public profile pictures accounts can pick.

  avatar-slot-01.png ... avatar-slot-06.png   the slots listed in
                                              app/lib/profile/avatar-catalogue.ts
                                              (square, 256x256)

  uploads/                                    pictures filed through the
                                              "CUSTOMISE PUBLIC PROFILE" console
                                              (POST /api/profile/avatar)

Nothing in this folder is generated: every file is a hand-drawn PNG (or JPG /
WEBP / GIF for uploads) added by hand. While a slot file is missing the picker
and the profile page show "[ ARTWORK FILE NOT FOUND ]" naming the path they
wanted, so an empty slot is obvious rather than a broken image.

Uploads are written here by the app itself, which means they show up in
git status - commit the ones that belong on the site.
