## Ideas, not code
The gap-closing and region work is written from the published paper: Fourey, Tschumperlé and Revoy, "A Fast and Efficient
Semi-guided Algorithm for Flat Coloring Line-arts". GIMP's implementation is GPL and was not read or copied. Other apps' ideas
(Harmony, Clip Studio, TVPaint, Krita, Blender, Fresco, OpenToon Studio, Celstomp, Callipeg, Procreate Dreams, Pencil2D) are listed
in the plan's table; no code came from any of them.
