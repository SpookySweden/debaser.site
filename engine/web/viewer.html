DRAWING

Only on this device. FAST takes each frame straight off the stream and puts it on a canvas that skips the browser's own drawing queue, so it reaches the screen sooner. NORMAL is the browser's own video player.

UPSCALING

Only on this device: nothing here is sent to the PC. OFF shows the picture at its real size, not stretched. SMOOTH stretches it to fill, softly. SHARP stretches it in hard squares (for pixel art). SHARPENED adds a sharpening pass on this device's graphics to every frame, which may add delay: that has not been measured.

MOUSE

POINTER: this device's own pointer is the pointer, drawn here with no delay; the stream itself carries no pointer. GAME: the pointer is captured and its raw movement is sent, for games that turn the view with the mouse.

The pointer is not captured: click the picture to capture it (Esc gives it back).

To let go: [ RELEASE ], or Ctrl+Alt+Shift+Q on this device (that is never sent to the PC). On the PC itself, Ctrl+Alt+Shift+End stops it. If this tab loses focus, every key held is let go at once.

  • Changing the PC's real screen mode, or a virtual screen, so that games draw themselves in this screen's shape instead of having their sides cut off.
